## What I've built

### [MyMDB](https://github.com/a-m-elshabrawi/mymdb) — private watch log for films and TV
Search any title against TMDB, then log that you watched it with a rating, a date, and a review. Over time it builds into a library, a diary, and a watchlist with a runtime filter. Multi-user, with every row scoped to its owner through Supabase row-level security. No public profiles or feeds — your data stays yours.

`Next.js 16` `TypeScript` `Tailwind v4` `shadcn/ui` `Supabase` `TMDB API` `Vercel`

### [Recomp](https://github.com/a-m-elshabrawi/recomp) — fitness tracking with an AI coach
A four-day bodyweight program with daily weight and nutrition logging, weekly check-ins, and progress charts. The coach runs on Gemini and gets your actual program and history as context, so it answers about your training rather than in generalities.

`Next.js 16` `TypeScript` `Supabase` `Recharts` `Google Gemini` `Vercel`

### [Hesabati](https://github.com/a-m-elshabrawi/hesabati) — Flutter fintech dashboard
One view across bank accounts, credit cards, and beneficiary cards, with transfers between them, spending analytics, and conversion across 150+ ISO 4217 currencies. Fully bilingual with RTL layouts and Material Design 3 theming. Built on mock account data as the final project for CODED's UniCODE program, and the project that won Best Project Idea from CODED and Boursa Kuwait.

`Flutter` `Dart` `Provider` `Material Design 3` `EN/AR + RTL`

### [Freezery](https://github.com/a-m-elshabrawi/Freezery) — kitchen inventory tracker
Tracks what's in your fridge, freezer, and pantry, and suggests restocks through a Llama model hosted on Groq. Vanilla JS frontend on GitHub Pages, Express and Postgres API on Render, JWT auth so it works cross-origin on mobile. The README has a rationale column explaining why each piece of the stack was chosen.

`Node.js` `Express` `PostgreSQL` `Groq` `JWT`

### [Flappy Bird 3D](https://github.com/a-m-elshabrawi/3d-floppy-bird) — Three.js game
The 2D original rebuilt in 3D with GLB models, dynamic lighting, and procedurally generated obstacles. I handled the game logic and physics.

`Three.js` `JavaScript`
